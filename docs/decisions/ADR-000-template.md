## 何时必须创建 ADR

以下情况**必须**创建 ADR（见 `.agents/rules/documentation.md` §5）：

- 引入或替换核心依赖 / 框架 / 数据库
- 改变系统架构（分层、模块边界、通信方式）
- 在有合理替代方案时做出有长期影响的选择
- 接受一项重要的技术债
- 推翻先前的 ADR

以下情况**不需要** ADR：

- 日常实现细节
- 可轻易回滚的局部变更
- 已被上级 ADR 覆盖的重复决策
