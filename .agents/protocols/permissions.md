# Protocol: Permissions

> 定义 Agent 的通用权限模型。**按 Role 授予权限，按风险追加约束。**

---

## 1. 权限维度

| 维度 | 含义 |
|------|------|
| **Read** | 读取文件 |
| **Write** | 修改文件 |
| **Execute** | 运行命令 / 脚本 |
| **Delete** | 删除文件 / 数据 |
| **Network** | 访问网络 |
| **Git** | 执行 Git 操作 |
| **Deploy** | 部署到环境 |

权限级别：

| 符号 | 含义 |
|------|------|
| ✅ | 允许 |
| ⚠️ | 有限 / 需条件 |
| ❌ | 禁止 |

## 3. 通用权限原则

### P1 — 最小权限

只授予完成任务所必需的权限。不为"方便"扩大权限。

### P2 — 默认拒绝

未明确授予的权限默认为**拒绝**。

### P3 — 职责分离

| 分离对 | 原因 |
|--------|------|
| 实现者 ≠ 批准者 | 防止自我批准 |
| 修复者 ≠ 验证者（关键路径） | 防止自证 |
| 部署者 ≠ 安全审批者 | 防止绕过安全 |

**这三对属于受保护规则**（已列入 `rule-precedence.md` §2），任何层级不得削弱。

**如何满足：** 可用 Agent 数量少于角色数量时，分配方案见 `role-assignment.md`。
其他角色可以兼任，**分离对不行**。

### P4 — 高风险追加约束

权限**不因 Role 而无限扩大**。即使 Role 允许某动作，
若该动作属于**高风险**（见 `change-safety.md`），仍需额外流程。

> **Role 权限决定"能不能做"；风险等级决定"要不要走审批"。**

### P5 — 不可自我提权

Agent **不得**修改自己的权限定义。
权限定义属于框架层，修改需人类批准。

---

## 4. 写权限的边界

`Write ✅` 不等于"可写任意文件"。写权限始终受以下约束：

1. **File Scope** —— 仅限 `TASK.md` 声明的范围。
2. **Role 边界** —— 仅限该 Role 的职责产物（如 Developer 不写架构文档）。
3. **受保护规则** —— 不得削弱 `security.md` 等。

---

## 5. 删除权限

**删除是最危险的操作。** 框架层面：

- 默认 ❌ 或 ⚠️，而非 ✅。
- 删除文件 → 优先使用可恢复方式（回收站 / 版本控制）。
- 删除数据 → 必须走 `change-safety.md` 的高风险流程。
- 禁止递归删除用户个人目录（Desktop / Downloads / Documents / Home）。
- 禁止 `rm -rf` 作用于宽泛路径。

## 6. 网络权限

| 场景 | 权限 |
|------|------|
| 读取公开文档 | ✅ |
| 下载依赖（已声明） | ✅ |
| 上传代码 / 数据到外部 | ⚠️ 需说明 |
| 访问生产系统 | ❌ 除非明确授权 |
| 发送外部消息（邮件/Webhook） | ⚠️ 需人类确认 |

---

## 7. Git 权限

| 操作 | 权限 |
|------|------|
| `status` / `diff` / `log` | ✅ |
| `add` / `commit`（任务分支） | ✅ |
| `push`（任务分支） | ✅ |
| `merge` 到 main | ⚠️ 需 Review PASS |
| `push --force` | ❌ 受保护规则禁止 |
| `reset --hard` / `clean -fdx` | ⚠️ 高风险，需批准 |
| 删除分支 | ⚠️ 需确认已合并 |

---

## 8. 部署权限

| 环境 | 权限 |
|------|------|
| 本地 | ✅ |
| 开发 / 测试 | ✅（DevOps） |
| 预发 | ⚠️ 需批准 |
| 生产 | ❌ 默认禁止；需**人类显式批准** |

---

## 9. 权限冲突处理

当 Agent 不确定自己是否有权限时：

1. **不要假设有权限。**
2. 查阅本协议 + 对应 Role 文件。
3. 仍不确定 → 停止并请求人类裁决。

> **宁可停下来问，也不要越权执行。**

---

## 10. 越权后果

越权操作可能导致：

- 数据丢失
- 安全漏洞
- 协作状态损坏
- 不可逆的历史改写

因此越权被视为**严重违规**，必须记录并复盘。
