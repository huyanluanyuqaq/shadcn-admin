# State — 跨项目全局状态

本目录只存放**真正跨项目**的状态。**保持最小。**

## 原则

> 状态优先靠近其所属的 Task。
> Task 状态 → 存在 Task 目录内（`TASK.md`）。
> Handoff → 存在 Task 目录内（`handoffs/`）。
> **只有无法归属到单个项目的全局状态，才放这里。**

## 允许的内容

| 内容 | 说明 |
|------|------|
| 全局任务索引 | 跨项目的 active 任务总览（可选） |
| 框架级决策记录 | 影响整个 Workspace 的决策 |
| 迁移记录 | 框架结构变更的历史 |

## 禁止的内容

- ❌ 具体项目状态（应在项目内）
- ❌ 具体项目的 Handoff（应在 Task 内）
- ❌ 项目源码或项目文档
- ❌ 临时数据 / 缓存

## 可选文件

| 文件 | 用途 |
|------|------|
| `active-tasks.md` | 跨项目 active 任务总览（可选维护） |
| `framework-decisions.md` | 框架层决策记录 |

> **注意：** 本目录为空是正常的。不要为了"填满"而创建无用文件。
