# src — 源代码

项目的源代码目录。

## 组织方式

按项目实际技术栈组织。**由 Architect 在 `docs/architecture/` 中定义**，此处给出通用建议：

```
src/
├── {{module-a}}/     ← 按模块/功能划分
├── {{module-b}}/
└── main.{{ext}}      ← 入口（如适用）
```

## 原则

- **按职责划分**，而非按类型划分（避免 `utils/` 成为垃圾场）。
- 模块之间保持**低耦合**，通过明确接口通信。
- 公共接口与内部实现分离。
- 不在此目录放测试（见 `tests/`）。

## 规则

- 遵循 `.agents/rules/coding.md`（Workspace 模式）或 `AGENTS.md` §10（Standalone）。
- 新增依赖前必须说明理由。
- 不提交密钥、构建产物、依赖目录。
