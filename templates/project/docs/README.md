# docs — 项目文档

本目录存放项目的全部文档。**文档与代码同源**，变更必须同步。

## 子目录

| 目录 | 内容 | 何时更新 |
|------|------|---------|
| `requirements/` | 需求：目标、用户、场景、验收标准 | 需求变更时 |
| `architecture/` | 架构：系统结构、模块边界、接口契约 | 接口/结构变更时 |
| `technical/` | 技术：实现细节、算法、配置 | 实现变更时 |
| `decisions/` | ADR：架构决策记录 | 重要技术决策时 |
| `operations/` | 运维：部署、监控、故障处理 | 部署方式变更时 |

## 写作规范

详见 `.agents/rules/documentation.md`（Workspace 模式）
或 `AGENTS.md` §12（Standalone 模式）。

**核心原则：**

- 结论先行
- 单一事实来源（引用而非复制）
- 具体可执行，避免空话
- 无密钥、无敏感信息

## 命名规范

- 文件名：小写 + 连字符（`payment-flow.md`）
- 每个文件仅一个 `#` 顶层标题
- 代码块标注语言
- 使用相对路径链接

## 模板

各子目录下以 `_template.md` 开头的文件为模板。
复制后重命名（去掉下划线前缀）再填写。
