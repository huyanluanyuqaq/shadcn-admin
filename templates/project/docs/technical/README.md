# technical — 技术文档

存放实现层面的技术文档。由 **Developer** 维护。

## 内容

| 文件 | 内容 |
|------|------|
| `coding-conventions.md` | 项目代码规范（对 Workspace `coding.md` 的补充） |
| `setup.md` | 本地开发环境搭建 |
| `{{topic}}.md` | 具体技术主题（算法、配置、集成等） |

## 与 architecture/ 的区别

| 目录 | 关注 |
|------|------|
| `architecture/` | **做什么** —— 结构、边界、契约 |
| `technical/` | **怎么做** —— 实现细节、算法、配置 |

## 写作要求

- 面向需要**修改代码**的开发者。
- 包含具体的文件路径、函数名、配置项。
- 算法要说明**为什么这样实现**，而不仅是步骤。
- 已知限制与陷阱必须写明。

## 何时更新

- 实现方式变更
- 新增依赖或配置项
- 发现非显而易见的陷阱
- 性能调优
