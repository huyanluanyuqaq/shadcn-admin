# tests — 测试

项目的测试目录。

## 组织方式

建议与 `src/` **镜像**，便于定位：

```
tests/
├── unit/          ← 单元测试
├── integration/   ← 集成测试
├── contract/      ← 契约测试（如适用）
└── e2e/           ← 端到端测试（如适用）
```

## 运行测试

```bash
{{test command}}
```

具体命令见 `AGENTS.md` §6。

## 规则

遵循 `.agents/rules/testing.md`（Workspace 模式）或 `AGENTS.md` §10（Standalone）：

- 测试必须**确定性**（不依赖时间、随机、网络、顺序）。
- 测试必须**独立**（可单独运行）。
- 每个缺陷修复必须附带一个**修复前失败、修复后通过**的测试。
- 覆盖正常路径、边界条件、异常路径。
- **不得**为了通过而删除/跳过测试或弱化断言。
