# scripts — 项目脚本

项目专用的脚本。

## 用途

| 脚本 | 用途 |
|------|------|
| `setup.sh` | 环境初始化（如需要） |
| `{{script}}` | {{用途}} |

## 规则

- 脚本必须**幂等**（可安全重复执行），或明确说明不可重复执行。
- 脚本必须**可读**：加注释说明用途与参数。
- 不在脚本中**硬编码密钥** —— 通过环境变量传入。
- 涉及**高风险操作**（删除、迁移、生产变更）的脚本必须在文件头注明，
  并在执行前走 `docs/operations/agent-constraints.md` 的高风险流程。

## 与 shared/scripts 的区别

| 位置 | 用途 |
|------|------|
| `shared/scripts/`（Workspace） | 跨项目复用（如创建新项目） |
| `<project>/scripts/` | 本项目专用 |
