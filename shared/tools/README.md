# tools — 可复用工具

存放**跨项目复用**的开发期工具。

---

## 允许的内容

| 类型 | 示例 |
|------|------|
| 提交信息校验工具 | 检查 Conventional Commits 格式 |
| 密钥扫描工具 | 提交前扫描敏感信息 |
| 结构校验工具 | 校验 Task / Handoff 文件完整性 |
| 文档链接检查 | 检查 Markdown 相对链接有效性 |

---

## 严格禁止

- ❌ 项目运行时依赖的代码（会破坏项目自包含）
- ❌ 项目专用工具（应在项目 `scripts/` 内）
- ❌ 密钥 / 凭据

---

## 判定标准

> 若某工具**被项目运行时需要** → 它不属于 `shared/tools/`。
> `shared/tools/` 只放**开发协作期**使用的辅助工具。
