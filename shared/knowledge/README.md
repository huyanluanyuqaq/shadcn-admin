# knowledge — 共享知识

存放**跨项目复用**的知识资产。

---

## 允许的内容

| 类型 | 示例 |
|------|------|
| 规范摘要 | 编码规范速查、Git 提交速查 |
| 检查清单 | 评审清单、发布清单 |
| 常见陷阱 | 各语言/框架的常见坑（技术栈无关的表述） |
| 术语表 | 团队术语统一 |
| 学习资源 | 有价值的文章、规范链接 |

---

## 严格禁止

- ❌ 项目专用知识（应在项目 `docs/` 内）
- ❌ 项目源码或配置
- ❌ 密钥 / 凭据
- ❌ 未经核实的"最佳实践"（须标注来源）

---

## 与 `.agents/rules/` 的区别

| 位置 | 性质 | 是否强制 |
|------|------|---------|
| `.agents/rules/` | **规则** —— Agent 必须遵守 | ✅ 强制 |
| `shared/knowledge/` | **知识** —— 参考信息 | ❌ 参考 |

> 规则放 `.agents/`，参考资料放这里。不要把规则写成"知识"来绕过约束。

## 添加规则

- 内容必须**技术栈无关**（技术栈相关内容放项目内）。
- 必须标注**来源与时效**。
- 区分**事实**与**观点**。
